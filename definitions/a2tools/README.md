# A2Tools monster names (GPL-3.0)

`names.json` holds monster names (id → name) taken from
[A2Tools](https://github.com/taengu/A2Tools-DPS-Meter) by taengu
(`src/data/i18n/npcs/en.json`, commit `652abd1`). It only contains the ids the
AION 2 Global Database (gaming.tools) doesn't list, such as zone and dungeon
variants (Vakron Sky Island 23008xx, open-world 24009xx).

the MIT licence. Daeva Meter reads this file as data; gaming.tools and our own
`definitions/names.json` win where they also have a name.
